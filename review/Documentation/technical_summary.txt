[size=6][b]PrintScreen V3 — Technical Summary[/b][/size]

[size=5][b]Architecture Overview[/b][/size]

PrintScreen V3 is a Skyrim Special Edition SKSE plugin written in C++20 (MSVC) with a Papyrus script layer that handles game-side UI, configuration persistence, and state management. The plugin captures the desktop framebuffer via the DXGI Desktop Duplication API and encodes it into one of seven supported image formats.

[size=5][b]Build System[/b][/size]

The project uses CMake 3.25+ with vcpkg for dependency management. The build targets MSVC with C++20 and produces a single DLL.

[size=4][b]Key Dependencies[/b][/size]

[list]
[*][b]CommonLibSSE-NG[/b] — SKSE abstraction layer. Provides Papyrus VM binding, address-library relocation, and RE (reverse-engineered) Skyrim headers. Sourced via a vcpkg registry (colorglass).
[*][b]DirectXTex[/b] — Microsoft's texture processing library. Used for [font=Courier New]ScratchImage[/font] management, DDS block compression (BC1–BC7), and WIC file I/O.
[*][b]DirectXTK[/b] — DirectX Tool Kit. Available for auxiliary texture operations.
[*][b]libpng / lodepng[/b] — Optional PNG libraries (linked if found). The primary PNG path uses WIC directly.
[*][b]spdlog + fmt[/b] — Logging framework. Wrapped in a [font=Courier New]logger[/font] namespace with level-aware convenience functions.
[/list]
[size=4][b]Precompiled Header[/b][/size]

[font=Courier New]pch.h[/font] includes CommonLibSSE-NG, Windows/COM, DirectX, WIC, and standard library headers. The [font=Courier New]Config.h[/font] header is included in the PCH so settings are globally accessible.

[size=5][b]C++ Module Breakdown[/b][/size]

[size=4][b]plugin.cpp — Entry Point[/b][/size]

Implements the three SKSE export functions:

[list]
[*][font=Courier New]SKSEPlugin_Query[/font] — version compatibility check.
[*][font=Courier New]SKSEPlugin_Version[/font] — declares plugin metadata, address library usage, and compatible runtime versions (1.5.39 through 1.6.1170).
[*][font=Courier New]SKSEPlugin_Load[/font] — initializes Config, sets up the logger, registers Papyrus functions via [font=Courier New]PrintScreenPapyrus::RegisterFunctions[/font], and logs a startup banner.
[/list]
[size=4][b]Config.h / config.cpp — Configuration[/b][/size]

Reads a Windows INI file from the SKSE folder. Supports two INI formats: a modern sectioned format ([font=Courier New][Logging][/font], [font=Courier New][Performance][/font], [font=Courier New][Capture][/font]) and a legacy flat format for backward compatibility. Unknown keys are detected and reported at startup.

Settings include log level (0–5), console/file output toggles, parallel compression enable, thread count, and capture progress logging. A [font=Courier New]Save()[/font] function writes current settings back, and [font=Courier New]SaveDefaults()[/font] creates a fresh INI with sensible defaults (DEBUG log level for new installs).

[size=4][b]PapyrusInterface.h / PapyrusInterface.cpp — Script Bridge[/b][/size]

Registers six native functions on the [font=Courier New]Printscreen_Formula_script[/font] Papyrus class:

| Function | Signature | Purpose |
|----------|-----------|---------|
| [font=Courier New]CheckPath[/font] | [font=Courier New]bool (string)[/font] | Validates and optionally creates the output directory. Performs a full read/write probe using a temp file. |
| [font=Courier New]TakePhoto[/font] | [font=Courier New]string (string, string, float, string, float, float, int, int, int)[/font] | Launches a detached worker thread for the requested capture. Returns immediately. |
| [font=Courier New]Get_Result[/font] | [font=Courier New]string ()[/font] | Returns the current state string. Consumes callback results (CALLBACK[i]SAVED, CALLBACK[/i]ERROR, CALLBACK_CANCELLED). |
| [font=Courier New]Cancel[/font] | [font=Courier New]string ()[/font] | Sets the atomic cancel flag. |
| [font=Courier New]ForceReset[/font] | [font=Courier New]string ()[/font] | Resets all state flags, clears the result, trims the memory pool. |
| [font=Courier New]ResetState[/font] | [font=Courier New]string ()[/font] | Alias for ForceReset. |

[size=3][b]Worker Thread Model[/b][/size]

[font=Courier New]TakePhoto[/font] validates the path, sets state flags ([font=Courier New]g_isStarting[/font], [font=Courier New]g_operationInProgress[/font]), stores [font=Courier New]"Running"[/font] in the guarded result string, and spawns a detached [font=Courier New]std::thread[/font] running [font=Courier New]CaptureWorkerThread[/font]. The worker routes to one of three internal functions based on the normalized image type string:

[list]
[*][font=Courier New]PerformImageCapture[/font] — single-frame formats.
[*][font=Courier New]PerformGifCapture[/font] — animated GIF.
[*][font=Courier New]PerformAPNGCapture[/font] — animated PNG.
[/list]
On completion (success, error, or cancellation), the worker stores a [font=Courier New]CALLBACK_*[/font] prefixed result string and sets [font=Courier New]g_resultReady[/font]. The Papyrus polling loop (OnUpdate) calls [font=Courier New]Get_Result[/font] to detect completion.

[size=3][b]Concurrency[/b][/size]

All shared state is protected by [font=Courier New]std::atomic<bool>[/font] flags and a single [font=Courier New]std::mutex[/font] guarding the result string. The cancel flag uses relaxed memory ordering for low-overhead cooperative cancellation.

[size=4][b]ScreenCapture.h / ScreenCapture.cpp — Capture Engine[/b][/size]

This is the core of the plugin at ~3,200 lines. Key subsystems:

[size=3][b]Desktop Duplication[/b][/size]

[font=Courier New]SetupDesktopDuplication[/font] creates a D3D11 device (hardware driver), walks the DXGI adapter chain to the primary output, and calls [font=Courier New]DuplicateOutput[/font] to get an [font=Courier New]IDXGIOutputDuplication[/font] interface. Cancellation is checked between each COM call.

[font=Courier New]CaptureSingleFrame[/font] acquires a frame (up to 5 retries with 1-second timeout each), copies the GPU texture to a CPU-readable staging texture, and memcpys the pixel rows into a [font=Courier New]DirectX::ScratchImage[/font]. Cancellation is checked every 100 rows during the pixel copy.

[size=3][b]Single-Frame Save Pipeline[/b][/size]

[list]
[*][b]WIC path[/b] (PNG, JPEG, BMP, TIF, static GIF) — [font=Courier New]SaveToWIC[/font] initializes COM, creates a WIC factory, and encodes the image. PNG uses a manual WIC pipeline (CreateBitmapFromMemory → WriteSource) to ensure correct BGRA color handling. JPEG uses a quality property bag. TIFF uses a compression-method property bag.
[*][b]DDS path[/b] — [font=Courier New]SaveToDDS[/font] calls [font=Courier New]DirectX::Compress[/font] with the selected BC format and [font=Courier New]TEX_COMPRESS_PARALLEL[/font] where possible, then [font=Courier New]SaveToDDSFile[/font]. Compression timing and ratio are logged.
[/list]
[size=3][b]Animated GIF Pipeline (Disk-Based)[/b][/size]

To avoid memory exhaustion on long captures, the GIF pipeline stores frames to disk as temporary BMP files during capture, then loads them one at a time during encoding:

[list=1]
[*]Capture loop: acquire frame → [font=Courier New]SaveTempFrame[/font] as BMP → release ScratchImage → sleep to next frame time.
[*]Fire [font=Courier New]onFramesCaptured[/font] callback (allows early HUD restoration).
[*]Encoding loop: load each BMP from disk → quantize to 8-bit indexed via WIC format converter → optionally compute differential region → write GIF frame via WIC encoder → release frame memory.
[*]Cleanup temp directory.
[/list]
[b]Differential GIF encoding[/b] (when [font=Courier New]gifCompression == 1[/font]):

[list]
[*]Quantize current frame to 8bpp using the previous frame's palette for consistency.
[*]Compare quantized pixels to find the bounding box of changed indices.
[*]If [font=Courier New]gifOptimize == 1[/font] (true delta): find the least-used color index, mark unchanged pixels with that index, set it as the GIF transparent color index. This allows GIF decoders to composite only changed pixels.
[*]If [font=Courier New]gifOptimize == 0[/font] (region only): extract the changed bounding box without transparency.
[*]Set disposal method to "do not dispose" (1) so the previous frame persists under the diff region.
[*]Use [font=Courier New]WritePixels[/font] instead of [font=Courier New]WriteSource[/font] for transparency frames to prevent WIC from re-quantizing.
[/list]
[size=3][b]Animated PNG (APNG) Pipeline (Disk-Based)[/b][/size]

Same disk-buffered capture loop as GIF. The encoding side manually assembles APNG chunks because WIC has no APNG encoder:

[list=1]
[*]Encode the first frame as a standard PNG via WIC.
[*]Parse its chunks (IHDR, IDAT, etc.) using a custom PNG parser ([font=Courier New]APNGHelper[/font]).
[*]Write PNG signature → IHDR → acTL (animation control: frame count, loop count) → fcTL (frame control for frame 0) → IDAT chunks from frame 0.
[*]For subsequent frames:
[/list]   - If differential encoding is enabled, compute the changed bounding box via [font=Courier New]ComputeAPNGDiffRect[/font] (per-channel threshold of 2 for noise tolerance).
   - If true delta ([font=Courier New]apngOptimize == 1[/font]): call [font=Courier New]ExtractDeltaSubRegion[/font] which produces a BGRA region where unchanged pixels are fully transparent (alpha=0). Encode with [font=Courier New]EncodeRegionToPNGWithAlpha[/font] to preserve the alpha channel.
   - If region-only: call [font=Courier New]ExtractSubRegion[/font] and encode with [font=Courier New]EncodeRegionToPNG[/font].
   - Parse the encoded region PNG's IDAT chunks.
   - Write fcTL (with x/y offsets, blend_op=OVER for diff frames) → fdAT chunks (IDAT data prefixed with sequence number).
[list=1]
[*]Write IEND.
[/list]
The [font=Courier New]APNGHelper[/font] namespace implements CRC32 calculation, big-endian I/O, and chunk read/write functions conforming to the PNG/APNG specification.

[size=3][b]MemoryPool[/b][/size]

A custom memory pool ([font=Courier New]memory_pool/MemoryPool.h/.cpp[/font]) provides reusable buffers for large BGRA frame data (~8 MB at 1080p). Key properties:

[list]
[*]On-demand allocation with best-fit block selection (no upfront pre-allocation).
[*][font=Courier New]PoolBuffer[/font] RAII wrapper — move-only handle that returns memory to the pool on destruction.
[*][font=Courier New]trim()[/font] releases idle blocks back to the OS.
[*]Safety features: double-free detection, block count warnings (256), unknown-pointer logging, destructor leak warnings.
[*]Thread-safe via internal [font=Courier New]std::mutex[/font].
[/list]
Currently integrated for the APNG [font=Courier New]prevFrameBuffer[/font] (the frame-to-frame comparison buffer). The GIF pipeline's [font=Courier New]prevQuantizedPixels[/font] still uses [font=Courier New]std::vector[/font] due to the complexity of its resize-on-every-frame pattern.

[size=3][b]Cancellation Model[/b][/size]

Two complementary mechanisms:

[list=1]
[*][b]Exception-based[/b] ([font=Courier New]CancelIfRequested[/font]): checks the atomic flag and throws a [font=Courier New]Cancelled[/font] exception. Caught at the top-level [font=Courier New]CaptureScreen[/font]/[font=Courier New]CaptureGIF[/font]/[font=Courier New]CaptureAPNG[/font] try-catch, which cleans up and returns a failure result.
[*][b]Return-code based[/b] ([font=Courier New]CheckCancellation[/font]): returns a bool. Used inside functions where exception unwinding would be problematic (e.g., inside COM/WIC callback lambdas, tight loops with resource handles).
[/list]
Both check [font=Courier New]g_cancelFlag[/font] which is set by the Papyrus [font=Courier New]Cancel()[/font] call.

[size=4][b]logger.h / logger.cpp / logger_shim.hpp — Logging[/b][/size]

Thin wrappers around spdlog. [font=Courier New]SetupLog[/font] creates file and console sinks based on Config settings. Log levels map to spdlog levels (0=off through 5=trace). The [font=Courier New]logger_shim.hpp[/font] provides [font=Courier New]logger::u8()[/font] wrappers for UTF-8 string logging.

[size=4][b]stringutils.h — String Conversion[/b][/size]

Inline [font=Courier New]utf8_to_wstring[/font] and [font=Courier New]wstring_to_utf8[/font] functions using the Win32 [font=Courier New]MultiByteToWideChar[/font] / [font=Courier New]WideCharToMultiByte[/font] APIs.

[size=4][b]cancel.h — Cancellation Helpers[/b][/size]

Standalone declaration of the [font=Courier New]Cancelled[/font] exception struct and [font=Courier New]CancelIfRequested[/font] inline function (also duplicated in [font=Courier New]screencapture.cpp[/font] for self-containment).

[size=5][b]Papyrus Script Layer[/b][/size]

[size=4][b]Printscreen[i]Formula[/i]script[/b][/size]

A stub script with [font=Courier New]Global Native[/font] function declarations that bind to the C++ registered functions. This is the bridge class — all native calls go through it.

[size=4][b]Printscreen[i]MainQuest[/i]script[/b][/size]

The primary quest script (~880 lines). Manages:

[list]
[*][b]Initialization[/b]: checks for SKSE, ConsoleUtil, JsonUtil, JContainers on [font=Courier New]OnInit[/font]. Reads or creates the JSON config.
[*][b]Game load recovery[/b] ([font=Courier New]OnPlayerLoadGame[/font]): re-registers mod events and hotkeys (which don't survive save/load), calls [font=Courier New]ForceReset[/font] on the native plugin, sanitizes all properties, recalculates FPS from Duration, clears stale capture flags, and force-restores the HUD.
[*][b]Capture orchestration[/b]: [font=Courier New]CaptureImage[/font] validates the path, sets state, hides the HUD, calls [font=Courier New]TakePhoto[/font], then starts a polling loop via [font=Courier New]RegisterForSingleUpdate[/font].
[*][b]Polling[/b]: [font=Courier New]OnUpdate[/font] checks for timeout (300s), calls [font=Courier New]Get_Result[/font], and dispatches to [font=Courier New]_HandlePollResult[/font]. The poll interval adapts — 0.1s for fast captures, 1.5s for long-running ones (AGIF, APNG, DDS BC6H/BC7).
[*][b]Result handling[/b]: [font=Courier New]_HandlePollResult[/font] parses the result string prefix (CALLBACK[i]SAVED, CALLBACK[/i]ERROR, CALLBACK_CANCELLED, etc.) and calls [font=Courier New]OnScreenshotCompleted[/font] for terminal states. In-progress states (Running, Starting, Cancelling) return false to continue polling.
[*][b]Hotkey[/b] ([font=Courier New]OnKeyUp[/font]): if a capture is active, pressing the key cancels it. Otherwise, it starts a new capture after a 0.75s debounce.
[*][b]HUD control[/b]: [font=Courier New]HideHUD[/font] / [font=Courier New]ShowHUD[/font] use [font=Courier New]ConsoleUtil.ExecuteCommand("tm")[/font] with a [font=Courier New]UI_Hidden[/font] flag to prevent double-toggling.
[*][b]JSON persistence[/b]: [font=Courier New]readJson[/font] / [font=Courier New]writeJson[/font] use PapyrusUtil's JsonUtil API. Every value is sanitized after reading (clamped ranges, valid enum strings, FPS recalculation from Duration).
[/list]
[size=4][b]Printscreen[i]MCM[/i]_Script[/b][/size]

Extends [font=Courier New]SKI_ConfigBase[/font] (SkyUI MCM framework). Builds a single "Settings" page with:

[list]
[*]Input field for path.
[*]Menu for image type selection (8 options).
[*]Toggle for automatic UI removal.
[*]Keymap selector for the photo key.
[*]Context-sensitive sliders and menus that enable/disable based on the selected image type (JPG quality, TIF mode, DDS mode, duration, loop count, differential compression, optimize, quality).
[*][font=Courier New]ResetFlags()[/font] helper that disables all format-specific widgets, called before selectively enabling the relevant ones.
[*]FPS auto-calculation in [font=Courier New]SetFPS()[/font] based on duration (15 fps for <4s, scaling down to 6 fps for >13s).
[*]Writes JSON on [font=Courier New]OnConfigClose[/font].
[/list]
[size=4][b]Printscreen[i]ME[/i]script[/b][/size]

A magic effect script that displays a MessageBox with the current configuration summary when activated (used as an in-game status spell).

[size=4][b]Printscreen[i]MAP[/i]script[/b][/size]

A key-code-to-name lookup utility using JContainers' JIntMap. Maps DirectInput scan codes (1–265) to human-readable key names.

[size=4][b]ArrayUtils[/b][/size]

Generic Papyrus array search helpers ([font=Courier New]FindString[/font], [font=Courier New]FindForm[/font], [font=Courier New]ContainsString[/font], [font=Courier New]ContainsForm[/font]).

[size=4][b]Printscreen[i]PlayerRef[/i]Script[/b][/size]

An empty ReferenceAlias script placeholder.

[size=5][b]Data Flow Summary[/b][/size]

[code]User presses hotkey
       │
       ▼
OnKeyUp (MainQuest script)
       │
       ├── If capture active → Cancel()
       │
       └── If idle → CaptureImage()
              │
              ├── HideHUD()
              ├── TakePhoto() [native call]
              │      │
              │      └── Spawns CaptureWorkerThread
              │             │
              │             ├── PerformImageCapture / PerformGifCapture / PerformAPNGCapture
              │             │      │
              │             │      ├── SetupDesktopDuplication
              │             │      ├── CaptureSingleFrame (loop for animated)
              │             │      ├── SaveToWIC / SaveToDDS / Encode GIF / Assemble APNG
              │             │      └── Return CALLBACK_SAVED / CALLBACK_ERROR
              │             │
              │             └── Store result in g_result, set g_resultReady
              │
              └── RegisterForSingleUpdate (poll loop)
                     │
                     ▼
              OnUpdate → Get_Result() → _HandlePollResult()
                     │
                     ├── Terminal → OnScreenshotCompleted → ShowHUD() + notify
                     └── In-progress → re-register poll
[/code]
