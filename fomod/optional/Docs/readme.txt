PrintscreenV3

Requirements:
- Skyrim Script Extender (SKSE)
- Compatible Skyrim runtime for the included DLL build

Installed files:
- SKSE\Plugins\PrintscreenV3.dll
- Data\Scripts\PrintscreenV3.pex

Optional files:
- Data\Scripts\Source\PrintscreenV3.psc
- Changelog.txt

Notes:
- Use the AE/current runtime option if you are on modern Skyrim Anniversary Edition.
- Use the SE/older runtime option only if this archive includes a dedicated older-runtime DLL.
- If the mod does not load, verify SKSE installation and runtime compatibility.
